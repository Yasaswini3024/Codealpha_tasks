# Handwritten Character Recognition

## Objective

Recognize handwritten digits using Deep Learning.

## Dataset

MNIST Handwritten Digit Dataset

## Technologies

- Python
- TensorFlow
- Streamlit
- NumPy

## How to Run

Install packages

pip install -r requirements.txt

Train model

python train.py

Run application

streamlit run app.py

## Output

Predicts handwritten digits from uploaded images.
